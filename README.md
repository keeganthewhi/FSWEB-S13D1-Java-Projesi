## About

An introduction to the Java programming language covering fundamental syntax, data types, and basic program structure. This assignment builds the foundation for object-oriented programming concepts explored in later sprints.

## Key Concepts

- Java syntax and program structure
- Primitive data types and variables
- Control flow statements (if/else, loops)
- Methods and basic I/O operations
